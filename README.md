# NPTEL Ethical Hacking

My learning repository for the NPTEL Ethical Hacking course.

## About

This repository documents my learning through structured notes, command references, authorized practical labs, network traffic analysis, and revision exercises.

**Course:** [NPTEL Ethical Hacking](https://onlinecourses.nptel.ac.in/e-learning/course/noc26_cs157?unitId=122&lessonId=125)

## Learning Objectives

- Understand networking fundamentals and common security concepts.
- Learn reconnaissance and vulnerability assessment techniques.
- Practice packet analysis and protocol interpretation.
- Study cryptography and web application security.
- Document controlled security experiments and defensive mitigations.
- Connect attack behavior with network detection and investigation.

## Lab Documentation Standard

Each practical exercise should include its objective, prerequisites, lab environment, commands, observations, results, and defensive recommendations.

## Responsible Use

All experiments are intended for authorized, isolated learning environments. Do not scan, exploit, or access systems without permission.
